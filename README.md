# dotfiles

Personal dotfiles for divijg19.

## Installation

### Core Configuration Installer
```bash
curl -fsSL https://raw.githubusercontent.com/divijg19/dotfiles/main/install.sh | bash
```
> *<sub>Installs and symlinks core terminal & editor configs (`fish`, `nvim`, `ghostty`, `zed`, `starship`, `atuin`, `tmux`, `yazi`) into `~/.config`. View [install.sh](install.sh) to inspect.</sub>*

### Interactive Binary Demonstration
```bash
curl -fsSL https://raw.githubusercontent.com/divijg19/dotfiles/main/demo.sh | bash
```
> *<sub>Interactively selects, downloads pre-compiled releases, or locally builds/installs Go binaries (`Helm`, `Keen`, `Peony`, `Pulse`, `Sage`) into `~/.local/bin`. View [demo.sh](demo.sh) to inspect.</sub>*
